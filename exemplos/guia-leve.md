# Como solicitar um relatório de incidente

**Departamento:** SAC
**Responsável:** Time de suporte
**Revisado em:** 2026-11
**Vale para:** qualquer indisponibilidade percebida por cliente ou monitoramento
**Versão:** 1.0

# OBJETIVO DO DOCUMENTO

Depois de ler este guia, você consegue abrir um incidente com todos os dados
que a equipe técnica precisa — exemplo fictício para demonstrar o template leve.

# Passo a passo / Regras

1. Registre hora, sistema afetado e mensagem de erro exata.
2. Anexe captura de tela ou trecho de log (sem credenciais).
3. Classifique o impacto: total, parcial ou dúvida.

- Um incidente por causa provável, nunca um "pacotão".
- Dados comparáveis sempre em tabela, nunca só em parágrafo.

| COLUNA A | COLUNA B |
| --- | --- |
| Sistema | Horário da falha |
| Arquivos | 08:15 |

# Como verificar

O incidente aparece no painel com número, responsável e prazo — se não
aparecer em 5 minutos, repita o envio e avise no canal do time.
